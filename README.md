# funjson

占位仓库，尚无实际功能代码，具体功能会在之后陆续补充。当前版本仅提供包元信息（`__version__`），可用于验证安装是否成功。

## Install

```bash
pip install funjson
```

## 最小示例

```python
import funjson

print(funjson.__version__)
```
